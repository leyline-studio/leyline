# ADR 0001 — Rust comme langage unique

**Statut :** Accepté — 2026-07

## Contexte

Le moteur doit traiter des fichiers RAW de plusieurs dizaines de Mo avec des performances proches du C++, rester maintenable pendant des décennies, et être portable Windows/Linux/macOS.

## Décision

Tout Leyline est écrit en Rust : moteur, catalogue, CLI, application.

## Conséquences

* Performances natives sans garbage collector, sécurité mémoire garantie à la compilation.
* Un seul langage pour tout le workspace : pas de frontière FFI interne.
* FFI nécessaire vers les bibliothèques C (LibRaw, Lensfun, LittleCMS) — isolée dans les crates concernées.
* Le SDK Rust est un produit en soi (`leyline-sdk`).

## Alternatives écartées

* **C++** : performances équivalentes mais sécurité mémoire manuelle ; coût de maintenance à long terme supérieur.
* **Go** : GC inadapté au traitement d'image temps réel.
* **Python + noyau natif** : deux langages, frontière permanente, distribution difficile.
