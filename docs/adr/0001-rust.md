# ADR 0001 — Rust as the only language

**Status:** Accepted — 2026-07

## Context

The engine has to handle RAW files of tens of megabytes at performance close to C++, stay maintainable for decades, and be portable across Windows, Linux and macOS.

## Decision

All of Leyline is written in Rust: engine, catalog, CLI, application.

## Consequences

* Native performance with no garbage collector, memory safety guaranteed at compile time.
* One language for the whole workspace: no internal FFI boundary.
* FFI is still needed towards the C libraries (LibRaw, Lensfun, LittleCMS) — confined to the crates concerned.
* The Rust SDK is a product in its own right (`leyline-sdk`).

## Alternatives rejected

* **C++**: equivalent performance but manual memory safety; higher long-term maintenance cost.
* **Go**: a GC is unsuited to real-time image processing.
* **Python + a native core**: two languages, a permanent boundary, difficult distribution.
