# The RAW decoders this tree has been validated against (ADR 0086 §3).
#
# One version string per line, as `leyline_raw::decoder_version()` reports it.
# Blank lines and `#` comments are ignored.
#
# Adding a line is a deliberate act —
#
#   LEYLINE_BLESS_DECODER=1 cargo test -p leyline-raw --test decoder_version
#
# — and it means someone accepted that this decoder may render differently
# from the others in this list. `docs/pipeline.md` §5.1 counts the decoder
# among the terms of the bit-for-bit promise.
#
# ── What ships ────────────────────────────────────────────────────────────
#
# **0.22.2 is the pinned decoder, and every deliverable carries it** (ADR 0086
# §7, 2026-09-15). The Windows installer bundles `libraw_r-25.dll` built from
# that tag, the AppImage bundles the matching `.so` from
# `/opt/leyline/libraw-linux`, the dmg links the one in
# `/opt/leyline/libraw-macos`, and every packaging script refuses to run
# without its pinned prefix.
#
# 0.21.4, pinned from 2026-08-30, is no longer listed: no leg builds it. A
# machine still holding that prefix fails here, which is the point.
#
# ── Why 0.21.2 is still here ──────────────────────────────────────────────
#
# It is what Ubuntu 24.04 ships, so it is what a contributor gets from
# `apt install libraw-dev` and what `make check` runs against on a plain
# machine. Requiring the pinned prefix just to run the tests would make a
# first contribution harder for no gain.
#
# It is listed on evidence, and the evidence now says what it costs. On
# 2026-08-30 it was compared with 0.21.4 on ten real RAW files — Canon 60D
# and 5D Mark IV CR2s, and DNGs — through `decode_manifest.rs`: ten identical
# digests. On 2026-09-15 nine of those ten were decoded again with 0.22.2:
#
#   three identical; six differ, by 35 to 2,498 pixels out of 10 to 30
#   million, scattered through the frame, at most 12 levels out of 255,
#   with no mean shift on any channel.
#
# So a test run on 0.21.2 validates the code, not the shipped pixels: they
# are the same image, not the same bytes. `decodes.json` holds the 0.22.2
# digests for the six that moved, so `make test-raw` on 0.21.2 reports them.
