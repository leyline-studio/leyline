# Leyline Vision

## Mission

Créer une plateforme open source de développement RAW moderne, rapide et
durable.

### Principes

* Local First
* Non destructif
* Rapide
* Modulaire
* Pérenne
* Open Source

## Vision

Leyline n'est pas un clone de Lightroom. C'est un moteur de
développement photographique autour duquel plusieurs applications
peuvent être construites (Studio, CLI, SDK).

## Public cible

Photographes amateurs exigeants, passionnés et développeurs.
